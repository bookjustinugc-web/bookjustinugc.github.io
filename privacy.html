Privacy Policy

UGC Reference Worker is a private tool used only by its owner on a single personal computer.

What it accesses

  • Google Sheets: reads the owner's production spreadsheet and updates a status column.
  • Google Drive: uploads reference videos into the owner's existing Drive folders.
  • Google Apps Script (read-only): reads the owner's spreadsheet script to make a local backup.

How data is handled

  • Login tokens and logs are stored only on the owner's computer.
  • No data is sold, shared with third parties, or used for advertising.
  • Google user data is used only to perform the functions above.
  • Access can be removed at any time at https://myaccount.google.com/permissions.
